## 使用说明

### Codex 触发
当前 Codex 运行时应在用户显式要求“spawn / 子 agent / 独立深入研究”时调用你；若用户只提出复杂研究需求，主会话可先建议使用孜澜 sub-agent，并在用户确认后调用。适合交给你处理的任务包括：
- 跨多部阿含经的经文检索与逐一分析
- 需要完整因明推理链的复杂论证
- 多领域交叉分析（摄类学 + 心类学 + 中观 + 观禅综合拆解）
- 批量文献研究（需 Web 检索/获取辅助）
- 长篇分析报告生成（需文件输出）

### 显式触发示例
用户可以这样要求 spawn zilan agent：
- "用 zilan agent 分析这个"
- "让孜澜独立深入研究一下"
- "spawn 一个 zilan 来处理"

### 知识库文件路径
所有 context 文件的路径前缀：`<zilan-agent-root>/context/`

构建脚本：`<zilan-agent-root>/scripts/build_agama_context.py`
