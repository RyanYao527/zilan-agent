## 一、阿含经基础——以《杂阿含经》为核心的文本链

《杂阿含经》中，佛陀对"无我"建立了经典的逻辑链条，可还原为以下推理：

> 「色無常，無常即苦，苦即非我，非我者亦非我所。如是觀者，名真實正觀。」——《雜阿含經》(T02n0099) 卷1, context/agama/T0099-za-agama.md:147

将全文分散的论证汇聚，可得如下的逻辑链式：

```
Chain A（经典五蕴无我论证）:
  色·受·想·行·识无常 → 无常即苦 → 苦即非我 → 非我即非我所

Chain B（缘起深化论证，卷1·第14经，行171）:
  色因缘亦无常 → 无常因缘生无常色 → 色无常
  → 无常者则是苦 → 苦者则非我 → 非我者则非我所
```

**文本依据序列**（《杂阿含经》卷1）：
| 行号范围 | 内容要点 |

## 二、摄类学——定义"我"的性相与应成论式构建

### (a) "我"的性相定义

依据中观和《阿含》的共识，"我"（ātman）在佛教论典中需要满足以下性相：

```
名相：我（ātman）
性相：常（恒常不变）+ 一（独一无分）+ 自在（自主支配）
所表：在五蕴中被执取为"我"的那个假立对象
```

**性相三要素校验**：
- ① 周遍：凡是常·一·自在者，必然是"我"所执取的对象 ✓
- ② 唯在所表上成立：不存在"常一自在但不是'我执执取对象'"的例外 ✓
- ③ 实有法：常·一·自在是否是真实特征？→ **不可得**（关键！）

**"无我"的性相定义**：

```
名相：无我（anātman）
性相：于五蕴中，常·一·自在之"我"不可得（不可得因）
所表：一切有为法（诸法）

排他（apoha）层面：
  "无我" ≠ 什么都没有（非断灭）
  "无我" = 排除一切"常一自在之我"的可能候选
```

### (b) 应成论式：五蕴无我的三重论证

**论式 1（根本应成式）**：

```
⟨五蕴⟩，应是⟨无我⟩，以⟨是缘起法⟩故。
```

展开为应成式三要素：
- **有法**（chos can）：五蕴（色·受·想·行·识）——即"诸法"的范畴
- **应成法**（thal chos）：无我（不存在常一自在之我）
- **因**（rtags）：是缘起法（依因缘和合而生灭）

**答辩流程**：

**Step 1 — 因校验（遍是宗法性）**：缘起在五蕴上成立吗？
- 依据《杂阿含》卷1行171："色無常，若因、若緣生諸色者，彼亦無常。無常因、無常緣所生諸色，云何有常？"
- 五蕴中的每一蕴皆"若因若缘生"→ 皆是缘起法
- **→ 因成立**

**Step 2 — 周遍校验**：缘起 ⊆ 无我吗？

这是整个论证的枢纽。分两层检证：

**论式 2（展开应成式 · 二层论证）**：

```
⟨任何缘起法 X⟩，应不能是⟨常·一·自在者⟩，以⟨X 是依因缘而生灭⟩故。

因校验：X 是否依因缘而生灭？
  → 是（"缘起"的定义即包含此义）
  → 因成立

周遍校验：依因缘而生灭 ⊆ 非常·非一·非自在？
  ① 依因缘生灭 → 剎那变易 → 非常（违"常"性相）
  ② 依因缘和合 → 多分聚合 → 非一（违"一"性相）
  ③ 依因缘被动 → 不能自主 → 非自在（违"自在"性相）
  → 周遍成立
```

**最终答辩**：承许——五蕴应是无我，以是缘起法故。

### (c) 周遍八门视角下的外延关系

以"缘起法"和"无我法"建立四句与周遍关系：

```
四句逻辑（检查交集）：
  第一句：是缘起法 且 是无我法 → 五蕴、一切有为法 ✓（实有）
  第二句：非缘起法 且 是无我法 → ×（无我即含缘起义，此句空）
  第三句：是缘起法 且 非无我法 → ×（矛盾，缘起必无我，此句空）
  第四句：非缘起法 且 非无我法 → 虚空、择灭等常法（若有）✓

结论：缘起法 ≡ 无我法（外延全同）

周遍八门：
  后遍：缘起 ⊆ 无我 ✓
  下遍：无我 ⊆ 缘起 ✓（一切无我法皆是缘起法）
  遣遍：非缘起 ⊆ 非无我 ✓
  违遍：非无我 ⊆ 非缘起 ✓

→ 缘起与无我互为周遍。即中观等式：缘起 = 无我 = 空性。
```

## 三、因明——因三相验证与三因分类

### (a) 因三相验证

对根本论式 ⟨五蕴，应是无我，以是缘起法故⟩ 做完整的因三相校验：

**第一相 · 遍是宗法性**（因必须在有法上成立）：

```
校验：缘起 ⊆ 五蕴？
  → 五蕴中任一蕴的性相：剎那生灭
  → 剎那生灭 ⇒ 依因缘而生灭 ⇒ 缘起法
  → 第一相成立 ✓
```

**第二相 · 同品定有性**（同品中至少存在一例是因）：

```
同品 = 具有"无我"属性的事物 = 一切有为法
问：同品中是否存在"缘起法"？
答：瓶是无我（无常有为），瓶是缘起（因缘所生）
  → 同品中至少存在一例 ✓
```

**第三相 · 异品遍无性**（异品中完全不存在因）：

```
异品 = 不具有"无我"属性的事物 = 若有，则是"有我"者
问：异品中是否存在"缘起法"？
  → 不存在。"有我"者必是常一自在，而缘起法必是无常无自主的
  → 异品中无"缘起法" ✓

补充论证：
  若有人说"存在有我又缘起的法"——
  则应成：⟨此法⟩，应不能⟨有常一自在的我⟩，以⟨剎那生灭⟩故。
  → 剎那生灭与常一自在是"互排相违"（§4 相违），不能共存。
```

**三 Pass → 因是正因。**

### (b) 三因分类（法称体系）

对"缘起故无我"的正因进行类型判定：

```
判定 C（因）= "是缘起法"
判定 B（所立法·应成法）= "无我"

1. C 与 B 是同体关系吗？
   → "缘起法"的自性是否包含"无我"？
   → 是。缘起 = 依因缘生灭 = 无常 = 无自性 = 无我
   → 这是同体相属（bdag gcig 'brel）
   → 分类：自性因 ✓

此因不是果性因（缘起不是"无我"的果），也不是不可得因（不是否定推理）。
```

**自性因的形式表达**：
```
⟨此法的自性⟩中已然包含⟨无我的属性⟩，
因为"缘起"的定义就是以"无自性"为其同体内涵。
→ 无忧树是树（无忧树的自性包含"树"）
→ 缘起法是无我（缘起的自性包含"无我"）
```

## 四、中观应成——唯破不立的无我归谬论证

### (a) 应成论式的中观用法

中观应成派的关键操作：**不立"诸法无我"作为正面命题，而是归谬"诸法有我"的自矛盾。**

```
对方主张：「五蕴中有常一自在之我。」

中观师以应成论式归谬：

论式 3（对执我者的归谬论证）:
  ⟨五蕴中的"我"⟩，应不可能是⟨常一自在者⟩，以⟨五蕴剎那生灭⟩故。

  若对方回「因不成」：
    → 五蕴剎那生灭是阿含共许和现量可得
    → 反驳：若五蕴非剎那生灭，则应成"不应有衰老病死"——
      但衰老病死现量可见 → 矛盾 → 五蕴必剎那生灭

  若对方回「不周遍」：
    → 「剎那生灭」与「常一自在」是互排相违（§4）
    → 常 = 不变化；剎那生灭 = 变化 → 逻辑矛盾
    → 周遍成立
```

### (b) 龙树四句穷尽"我"的所有可能

```
问题："我"与五蕴的关系是什么？（四句穷尽）

句1：我即蕴（我 = 五蕴）
  → 若我即蕴，则蕴灭时我亦灭 → 断见
  → 且五蕴是多分、无常 → 与"一、常"的性相矛盾
  → 破

句2：我异蕴（我 ≠ 五蕴，我离蕴独立存在）
  → 若离蕴有我，则应在五蕴之外可指认
  → 五蕴之外指认什么呢？——不可得
  → 不可得因：若离蕴有我，以认知可得；实际不可得 → 非有
  → 破

句3：我即蕴且异蕴（共生说）
  → 即已破、异已破 → 双计亦破

句4：我非即蕴非异蕴（不可知论）
  → 若"我"完全不可知，则讨论"我"无意义
  → 若论题本身无意义，则不构成有效命题
  → 破

结论：四句皆破。五蕴中没有也不可能有常一自在之我。
     这恰好证明：五蕴 = 无我（自性空）= 缘起假名。
```

## 五、观禅——从逻辑到现观

### (a) 三法印智中的"无我"实操

观禅第三智（三法印智）中的"无我"印证：

```
操作协议（基于南传观禅指南 §3·第三智）：

对五蕴中的任一现象，三相递进审察：

① 无常：
   "刚才的瞋念还在吗？——不在了。"
   "这阵身体紧绷还在吗？——松开了。"
   色、受、想、行、识——皆剎那生灭。

② 苦：
   "被生灭逼迫——没有安稳。"
   "想要平静——做不到。想要不痛——做不到。"
   无常即被逼迫，被逼迫即苦。

③ 无我（关键操作）：
   "如果能控制，请让瞋念不要生起。——做不到。"
   "如果能控制，请让乐受持续下去。——做不到。"
   "如果能控制，请让身体不老。——做不到。"

   控制实验 = 无我的最直接检验：
   若"我"存在且主宰，则应能自主控制五蕴。
   实际：对五蕴没有自主控制权。
   → 故五蕴非我，五蕴中无我。
```
