## 以应成法破"诸法自性有"的系统方案

### 一、总策略："不立自宗，唯破他执"

应成派不自己建立"诸法无自性"作为独立命题去论证，而是从对方的"诸法自性有"出发，**推导出对方自身无法接受的自相矛盾**。这是关键——你不必让对方先接受中观的前提，只需用对方已有的认知中的事实反戈一击。

### 二、通用论式模板

以"缘起"为矛，攻击"自性有"：

```
⟨ 诸法（任一具体法 X）⟩，应是⟨无自性⟩，以⟨是缘起法⟩故。
```

对方若承许"X 有自性"，则按应成论式的两种答辩路径必定触发矛盾：

**路径一：因不成（因不成立）**
- 对方必须否认 X 是缘起法——即声称 X 不依赖任何因缘而独立存在
- 这在现量/比量上站不住：色法待因缘生、心识待所缘与作意生、乃至抽象概念也依赖语言和思维的因缘——没有任何法能脱离因缘

**路径二：不周遍（因不推出应成法）**
- 对方承认 X 是缘起法，但声称"缘起 ≠ 无自性"
- 此时需展开：自性的定义 = 不依赖因缘、独立自存。若 X 自性有，则 X 的这一"自性"必须是：① 不观待因缘而存；② 不观待支分（部分）而存；③ 不观待名言分别而存。但承认 X 是缘起法就是承认 X 观待因缘、观待支分——**自性有与缘起在逻辑上是互排相违（phan tshun spangs pa'i 'gal ba）**，不能同时成立。

```
自性 ∉ 缘起 → 承许"缘起 & 自性" = 承许互排相违的两法同时成立 → 矛盾
```

### 三、六条具体攻击路线

以下六条线可独立或组合使用，每条都以应成论式从"若自性有，则应成……"出发：

#### 路线 ①：缘起直破（基础版）

```
有法：任一缘起法 X（如眼识）
应成法：无自性
因：是缘起法故

对方答辩 → 必落"因不成"或"不周遍"
→ 因不成：X 不是缘起法？现量可破
→ 不周遍：若 X 缘起而有自性，则"自性"可随因缘变化，与"自性不变"自相矛盾
```

#### 路线 ②：金刚屑因——破"有自性的生"

```
有法：X 的生起
应成法：不是自性有的生
因：若有自性的生，必是自生、他生、共生、无因生四者之一，
    四者皆不可能故

→ 自生（数论）：果若已在因中有，生是多余；若不在，则非自生
→ 他生（胜论/经部）：若因与果是"他性"，则一切可从一切生
→ 共生（耆那）：自他各自已破，合亦不成
→ 无因生（顺世）：则一切恒常或恒无，违背世间因果
```

#### 路线 ③：离一离多（本体论归谬）

```
有法：X（任法）
应成法：无自性
因：非一非多故

→ 若 X 有自性，则 X 的自性要么是"一"（整体性自存），
   要么是"多"（以多个自性部分聚合）
→ 若"一"：X 无支分则不可分析、不可感知——与经验矛盾
→ 若"多"：X 由多个有自性的部分组成，每个部分又可以同一逻辑再分析
   → 无限回溯（regressus ad infinitum）
→ 成立：X 既非一也非多 → X 无自性
```

#### 路线 ④：七相推求——破"自性的我"

月称针对"补特伽罗我"的七相无车喻，可直接泛化到一切法：

```
若 X 有自性（自性 = X 的本质或独立自体），则 X 与"其自性"的关系必落七相之一：

① 一体：X = 自性 → 则"X 有自性"是同义反复，不增加任何信息
② 异体：X 之外另有自性 → 则自性独立于 X 存在 → 荒谬：瓶的自性不依赖瓶？
③ 能依：自性依于 X → 谁先谁后？若自性先有，则"自性"依于不存在的 X
④ 所依：X 依于自性 → 同上循环
⑤ 具有：X 具有自性 → "具有"本身是缘起还是自性？若自性，则"具有自性"本身
    也需再推求其自性 → 无限回溯
⑥ 总聚：X 是自性与其他部分的聚合 → 总聚无自性（观待支分）
⑦ 形状：X 以某种方式由自性与部分结合 → 同⑤⑥

→ 七相皆不成立 → "X 有自性"不成立
```

#### 路线 ⑤：二谛归谬——世俗中能否找到自性？

```
有法：诸法的世俗显现
应成法：不应被视为"自相有"的证据
因：世俗谛的定义本身就是"无明所覆的凡夫所见"，
    不是"客观实在"的描述

→ 月称立场（比自续派更彻底）：
   世俗中亦不承许有自相——因为"自相"这个概念本身就是无明的产物。
   即使日常言说层面，"瓶"也是依赖陶土、工匠、火烧、命名的缘起现象，
   从未有一个不依赖这一切的"瓶自性"被任何人直接经验过。
   
   自续派说"世俗中可承许有自相"——
   但若"世俗中有自相"成立，则世俗中应能找到"自相"的实例。
   找一个。找不到 → 即使在世俗层面，自性有也是颠倒知。
```

#### 路线 ⑥：排他语义学破——"自性"这个概念本身的不自洽

```
有法：概念"自性"
应成法：不应承许为有意义的正相概念
因：依排他（apoha）理论，一切概念的意义来自排除互排相违者，
   "自性"排除的是"观待因缘"——
   但排除"观待因缘"后，概念本身也无法在认知中安立
   
→ 若"自性"排除了一切"观待"的特征，则：
   "自性"不能被认知（认知即观待）
   "自性"不能被言说（言说即观待名言）
   "自性"不能被论证（论证即观待因明）
→ 承许"诸法自性有"的人，自己无法不依赖"观待"来表述这个主张
   → 自相矛盾：主张的行为否定了主张的内容
```

### 四、应成论式在破自性见中的特殊变形

与摄类学标准论式相比，中观应成式有一个关键变形——**可以接受因不成，但要求对方亲证**：

```
标准论式：⟨X，应是无自性，以缘起故⟩
对方答"因不成" = 否认 X 是缘起法
回应：请在世间找一个"不观待任何因缘而存在"的法，举一个例子。
```

这里的应成策略不是硬推对方接受，而是把举证责任翻转给对方。因为"非缘起法"在任何已知经验范围内找不到一个实例，不需要用不可得因去"证明不存在"——对方举不出就是因不成之因不成。

### 五、操作协议总结

```
破"诸法自性有"的应成流程：

1. 让对方明确所执的"自性"定义
   → 摄类学 §1 性相校验：自性 = 不观待因缘、不观待支分、不观待名言
   → 若对方定义不同，先对齐定义

2. 取对方承许为缘起法的任一具体法为其有法
   → 对方若不承许任何法是缘起法 → 举证责任翻转到对方（举一个非缘起法）
   → 对方若承认"有些法是缘起法，但仍有自性" → 进入步骤 3

3. 构建应成论式：⟨该缘起法⟩，应是⟨无自性⟩，以⟨缘起 = 观待因缘支分⟩故
   → 对方答"因不成" → 对方须证明该法不观待因缘支分 → 不可能
   → 对方答"不周遍" → 需证明"观待因缘"与"有自性"可并存 → 互排相违，不可能

4. 多条路线轮番攻击，直至对方认识到：
   不是"中观师在论证无自性"，
   而是"自性有"这个主张在其自身逻辑中就站不住。

5. 证成后——仅用无遮遮止（摄类学 §7）：
   "诸法无自性"不代表"诸法是别的东西"。
   不说"诸法是什么"——只说"自性有不成立"。
   这就是"破而不立"。
```
