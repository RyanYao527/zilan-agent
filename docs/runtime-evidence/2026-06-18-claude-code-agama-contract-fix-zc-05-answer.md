# 诸法无我：应成论式 → 阿含 · 摄类学 · 因明 · 观禅串联分析

## 一、阿含文本基础——佛陀的"非我"论证

阿含经中，佛对"无我"的核心论证不是直接宣称"没有我"，而是通过**缘起观察链**逐层推出"非我"结论。最经典的公式见于《杂阿含经》卷一：

> **「色無常，無常即苦，苦即非我，非我者亦非我所。如是觀者，名真實正觀。」**
>
> ——《雜阿含經》(T02n0099) 卷 1, （九）, context/agama/T0099-za-agama.md:147

这一公式的完整逻辑链：

```
色（五蕴）无常 → 无常即苦 → 苦即非我 → 非我即非我所
```

《杂阿含经》卷一的（一一）经进一步展开了因缘论证：

> **「色無常，若因、若緣生諸色者，彼亦無常。無常因、無常緣所生諸色，云何有常？如是受、想、行、識無常……無常者則是苦，苦者則非我，非我者則非我所。」**
>
> ——《雜阿含經》(T02n0099) 卷 1, （一一）, context/agama/T0099-za-agama.md:171

这个论证的力度在于：不仅果（五蕴）是无常的，**连生起五蕴的因和缘本身也是无常的**——无常因 + 无常缘 → 怎么可能产生常果？这是彻底的缘起无我论证。

《中阿含经》卷十一则以「十一门」（过去·未来·现在·内·外·粗·细·好·恶·远·近）穷尽一切可能，得出同一结论：

> **「若有色，或過去、或未來、或現在，或內、或外，或麤、或細，或好、或惡，或近、或遠，彼一切非我，非我所，我非彼所，當以慧觀知如真。」**
>
> ——《中阿含經》(T01n0026) 卷 11, context/agama/T0026-zhong-agama.md:3663

## 二、摄类学——概念拆解与论式地基

### 2.1 「我」的性相定义（§1 性相与所表）

在构建应成论式之前，必须先定义「我/自性」的性相：

```
名相：我 / 自性（ātman / svabhāva）
性相：常·一·自在 —— 不依赖因缘、独立自存、具主宰性的实体
所表：一切被执为"我"或"我所"的法

校验：
  ① 凡常一自在者，必然是"我/自性" → ✓ 周遍
  ② 不存在"常一自在但不是自性"者 → ✓ 唯在所表上成立
```

### 2.2 「无我」的定义——通过排他（§7 排他）

阿含的「非我」表述正好对应摄类学的**排他（apoha）**机制：

```
「无我」不是正面建立某个叫"无我"的实体
「无我」= 排除"常一自在之我"在五蕴上的成立
        = 无遮遮止（只否定，不隐含正面替代）
```

五蕴是「非我」——不是先有一个"真我"再否定它，而是：**就五蕴本身的性相而言，找不到常一自在的特征。**

### 2.3 关键相违关系（§4 相违与相关）

```
「缘起无常」与「常一自在」= 互排相违（逻辑层面）
二者不能同时在一个有法上成立

无常 ⇔ 常      互排相违
缘起 ⇔ 自性有  互排相违
五蕴 ⇔ 我      不并存相违？→ 更精确：五蕴的性相（无常）与我之性相（常）互排
```

## 三、应成论式——逐层归谬论证

### 3.1 主论式

```
【论式 1——根本论证】

⟨五蕴（色受想行识）⟩，
应是⟨无我（非常一自在之我）⟩，
以⟨是缘起无常法⟩故。
```

**应成论式完整结构**：

```
有法（chos can / subject）：        五蕴（色·受·想·行·识）
应成法（thal chos / predicate）：    无我（非常·一·自在）
因（rtags / reason）：              缘起无常法
```

### 3.2 论式逐层展开

**三种答辩的精确判定**（摄类学 §6 三步校验）：

---

**Step 1：因校验——「缘起无常法」在五蕴上成立吗？**

使用 §1 性相与所表：五蕴的性相是什么？

- 色蕴 = 变碍（rūpa = rūpyate, 变坏/质碍）→ 本质即无常
- 受蕴 = 领纳 → 触缘生受，触灭受灭 → 无常
- 想蕴 = 取相 → 根尘识三合触生想 → 无常
- 行蕴 = 造作 → 思心所发动，刹那生灭 → 无常
- 识蕴 = 了别 → 根尘为缘生识 → 无常

五蕴的性相中已经包含「缘起无常」。使用 §3 一与异：五蕴与缘起无常法至少是**返体一**（同一概念类别）。

→ **因成立**。

---

**Step 2：周遍校验——「缘起无常法」周遍于「无我」吗？**

这是论证的核心。需要证明：凡是缘起无常法，必然是无我（非常一自在之我）。

使用 §5 周遍八门中的**后遍**：因 ⊆ 应成法 → 「缘起无常法 ⊆ 无我」成立吗？

**归谬式周遍证明**（中观应成方法论，取对方前提推导矛盾）：

> 对方主张：存在一个法 X，它既是缘起无常法，又具有常一自在之我。

```
若 X 有常一自在之我：
  → 常 = 不变化、不生灭
  → 自在 = 不依赖他缘

但 X 又是缘起法：
  → 依因缘而生
  → 因缘变化则 X 变化

矛盾：
  不变化（常）∧ 变化（无常因缘所生）→ 逻辑互排
  不依赖他缘（自在）∧ 依因缘而生 → 逻辑互排

结论：不存在"既是缘起无常法又是常一自在之我"的法。
∴ 缘起无常法 ⊆ 无我（后遍成立）
```

→ **周遍成立**。

---

**Step 3：最终答辩**

因成立（Step 1 ✅）且周遍成立（Step 2 ✅）→ **承许（'dod）**。

---

### 3.3 嵌套论证——处理可能的反驳

对方可能反驳：「缘起无常法」这个因本身就有自性。

此时使用**里层充塞论证**（摄类学 §6 五种应成论式立法类型）：

```
【论式 2——里层充塞】

⟨「缘起」这个性质⟩，应是⟨无自性⟩，
以⟨是依观待而安立的概念⟩故。

  若"缘起"有自性：
    → 缘起 = 不依赖因缘而成立的恒常属性
    → 但"缘起"这个概念本身依赖"自性"概念才能安立（观待）
    → "依因缘而生"的意义正是对"不依因缘"的否定
    → 若缘起有自性，则"缘起即无自性"的等义被破坏
    → 自相矛盾
```

这回到了中观的核心命题：**缘起 = 无自性**（《中论》二十四品·十八颂）。因本身也是无自性的，但这不妨碍它作为归谬论证中的工具——因为应成派**不立自宗**，因取自对方的前提。

## 四、因明验证——因三相与三因分类

### 4.1 因三相校验（因明 §1）

对主论式进行完整校验：

```
论式：⟨五蕴，应是无我，以是缘起无常法故⟩

Phase 1 · 第一相（遍是宗法性）：
  因（缘起无常法）在有法（五蕴）上成立吗？
  → 五蕴的性相 = 变碍·领纳·取相·造作·了别
  → 每一个的性相都包含"缘起无常"
  → §1 性相校验通过
  → ✅ 第一相满足

Phase 2 · 第二相（同品定有性）：
  同品（无我法）中至少存在一处是缘起无常法吗？
  → 同品定义：一切无我法（非常一自在者）
  → 瓶是无我法（非常一自在），瓶也是缘起无常法
  → ∃x: 无我(x) ∧ 缘起无常(x) 成立
  → ✅ 第二相满足

Phase 3 · 第三相（异品遍无性）：
  异品（有我法 / 常一自在法）中完全不存在缘起无常法吗？
  → 异品定义：常一自在者
  → 常一自在者 ≠ 缘起 → 不依因缘
  → 常一自在者 ≠ 无常 → 常
  → 缘起无常法 ∩ 常一自在者 = ∅
  → ✅ 第三相满足

三阶段全 PASS → 因是正因。
```

### 4.2 三因分类（因明 §2）

判定这个因属于法称三因中的哪一类：

```
因（缘起无常法）与所立法（无我）之间是什么关系？

判定流程：
  1. 因与所立法是同体关系吗？
     → "缘起"的自性是否包含"无自性"？
     → §4 相违与相关：缘起与无自性 = 同体相属
       （缘起的自性就是无自性——「众因缘生法，我说即是空」）
     → YES → 自性因（svabhāva-hetu）

  2. 检验：因是所立法的"别"吗？
     → "缘起无常法"是"无我法"的别（子类）
     → §2 总与别：凡是缘起无常法，必然是（别于）无我法
     → ✅ 自性因确认

分类结论：
  此因属于 自性因 ——
  因（缘起无常法）的自性本身就包含了所立法（无我）的概念。
  这是分析命题，不是综合命题。
  「缘起 → 无常 → 非我」的链实际上就是同体相属的层层递进。
```

### 4.3 阿含「无常→苦→非我」链的因明重构

阿含的三步推理可以映射为因明中的自性因链：

```
Step 1: ⟨五蕴，应是无常，以是因缘所生法故⟩
        因：因缘所生  所立法：无常  类型：自性因
        （「因缘所生」的自性包含「无常」）

Step 2: ⟨五蕴，应是苦，以是无常法故⟩
        因：无常      所立法：苦    类型：自性因
        （「无常」的自性包含「被生灭所逼迫」= 苦）

Step 3: ⟨五蕴，应是非我，以是苦法故⟩
        因：苦        所立法：非我  类型：自性因
        （「苦/被逼迫/不可控」的自性包含「非自主=非我」）

三环自性因链 → 每一步都是概念上的蕴含关系。
这恰好解释了为什么「如是观者，名真实正观」——
正观就是直接看到这些自性蕴含关系，不需要外求。
```

## 五、观禅串联——从逻辑论证到直接体证

### 5.1 论证链与观智的映射

上述逻辑论证的每一步，在南传观禅中都有对应的**直接体验层面**：

| 逻辑层面（因明/摄类学） | 体验层面（十六观智） | 对应操作 |
|---|---|---|
| 因缘所生 → 无常 | **名色分别智**（第一智） | 区分色法（物质现象）与名法（认知），看到每一个都在刹那生灭，没有一个停留 |
| 无常 → 苦 | **缘摄受智**（第二智） | 追查因果链：声波→耳识→苦受→瞋→身紧——自动化逼迫，非我能控 |
| 苦 → 非我 | **三法印智**（第三智） | 三相印证：每一念生起即灭（无常）、被生灭逼迫（苦）、不可控（非我） |
| 缘起 = 无自性（中观） | **生灭随观智**（第四智） | 标记"生、灭"——直接体证无一法能停留一刹那 |

### 5.2 观禅实操——「非我」的当下体证

观禅指南 §3 的第三智（三法印智）给出了验证「非我」的操作指令：

```
无我（anattā）的直接检验：
  
  "如果能控制，请让愤怒不要生起。——做不到。"
  "如果能控制，请让平静持续下去。——做不到。"
  
  凡是无常、苦的，不可能是"我"或"我的"。
  "我"的定义应该包含自主控制——但我们对名色法没有自主控制。
```

这恰好与《杂阿含经》卷一的（一一）经形成闭环——因是无常的、缘是无常的，所生的果（五蕴）怎么可能是（常的）我？

### 5.3 应成论式 Debug 与观禅的联合使用协议

根据南传观禅指南 §5 的联合使用协议，完整的「诸法无我」体证路径是：

```
Phase 1: 应成论式 — 逻辑归谬
  ⟨此身/心/念⟩，应是⟨非我⟩，以⟨是缘起无常法⟩故。
  → 因成立、周遍成立 → 承许
  → 逻辑上得出"非我"的结论
  → 立即暂停对"我"的执取反应

Phase 2: 心类学 — 认知状态判断
  当前执"我"的认知属于七种认知中的哪一种？
  → "此是我" = 颠倒知（viparyaya-jñāna）——对五蕴的性相做了错误判定
  → 不应依颠倒知行动

Phase 3: 南传观禅 — 直接体证
  在逻辑暂停的间隙，直接观察名色法的生灭：
    · 名色分别：「这是我」的念头——名法；胸口的紧——色法
    · 三相印证：这个念头正在变化（无常）→ 被逼迫（苦）→ 不可控（非我）
    · 生灭随观：标记……"生、灭"……"生、灭"

Phase 4: 返回逻辑 — 结论与体验合一
  观禅平息后回看：
  「刚才执"我"的那个认知——现在看，因还成立吗？」
  → 在平静中，逻辑结论与直接体验合一
```
