结论先行：**此论式不成立**，因「所知」属**共不定因**（sādhāraṇa-anaikāntika），因三相不圆满，不能证成「声是常」。

## 论式拆解

- **有法**（宗前陈/主词）：声
- **所立法**（宗后陈/谓词）：常
- **因**（理由）：所知（是认知的对象）

## 因三相逐相检验

| 三相 | 检验 | 判定 |
|------|------|------|
| **遍是宗法性** | 声是所知吗？是——声是认知的对象 | ✅ 成立 |
| **同品定有性** | 存在「既是常、又是所知」的同品吗？有——如虚空（常、所知） | ✅ 成立 |
| **异品遍无性** | 一切「无常」者皆非所知吗？**否**——如瓶，是无常，却是所知 | ❌ **不成立** |

## 症结

「所知」（jñeya）是**一切法的共相**，它周遍于常与无常二者——虚空是所知，瓶也是所知。因此在摄类学的总别关系上，「所知」是**总/上位概念**，「常」与「无常」都是其**别/下位**：

> 所知 ⊃ { 常法、无常法 }

正因必须满足「异品遍无」——即凡不具备所立法「常」者（无常），不得具有因「所知」。但瓶作为无常法却仍是所知，故「所知」**未能把常品与无常品区分开**，既在同品上存在（虚空），又在异品上存在（瓶），因而是典型的**共不定因**（因遍于同异二品，无法决定）。

## 判定

因三相缺第三相「异品遍无性」，故为似因（非正因）。「声，应是常，以是所知故」**不成立**；「所知」不能作为「常」的能立因。
