## 应成论式归谬三链

| 链 | 对方承许 | 归谬矛盾 |
|:--|:--|:--|
| **无常 vs 自性我** | 五蕴 = 常一自在的我 | 五蕴刹那生灭 ≠ 常，同一事物不能既常又无常 |
| **缘起 vs 自性** | 诸法有自性（不待因缘自存） | 诸法缘起 → 无自性（《中论》），故自性我不成立 |
| **自在 vs 不可控** | 我有自在控制权 | 实际对五蕴毫无自在（老病死不可令止） |

**断灭边界**：中观只破自性有，不破世俗缘起安立。把空性理解为断灭——因果业报不存在——是不成立的误读。胜义无自性，世俗仍可言说因果作用。
