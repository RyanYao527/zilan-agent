论式检验：`⟨声，应是无常，以是所知故⟩`

结论：论式不成立。返回状态为不周遍。第三相异品遍无性失败，`所知` 是共不定因。

### 论式拆解

| 要素 | 赋值 |
|---|---|
| 有法 | 声 |
| 所立法 | 无常 |
| 因 | 所知 |

### 因三相逐相校验

第一相遍是宗法性通过：`所知` 在 `声` 上成立，因为声是可被认知的对象。

第二相同品定有性通过：同品为无常法，瓶既无常又是所知。

第三相异品遍无性失败：异品为常法，而虚空、空性、择灭等常法也可以作为所知。由此可见，`所知 ∩ 异品 ≠ ∅`。

### 周遍判断

后遍：`所知 ⊆ 无常` 不成立，因为常法亦为所知。

遣遍：`¬无常 ⊆ ¬所知` 不成立，因为常法仍可作为所知。

结论：根本周遍不成立。该因无法证明 `声是无常`，应判为不周遍。
