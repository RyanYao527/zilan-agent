## 二、应成论式 / 对方承许 / 归谬 / 不立自宗 / 二谛 / proposition_decomposition

### proposition_decomposition

```
待分析命题：诸法有自性我（对方承许）
  ├── sub-claim 1：色/受/想/行/识各自中有"我"（即蕴我）
  ├── sub-claim 2："我"离五蕴别有（离蕴我）
  └── sub-claim 3："我"与五蕴相在（相在我）
```

### 对方承许

凡夫我执的核心命题：在五蕴上存在一个**自性我**——独立自存、常一自在的主体。可表现为即蕴我、离蕴我、相在我三种。

### 归谬（逐个击破）

**破即蕴我**：若色是我 → 应可自主转 → 事实于色病苦生不可自主 → 与"自性我"定义矛盾。

**破离蕴我**：若离蕴有我 → 应于蕴灭时别有所得 → 逐一剥除五蕴后无任何"我"残留 → 不成立。

**破相在我**：若我在蕴中 → 五蕴无常，"我"应随之变易 → 与"我"常一自在的定义矛盾。

**综合归谬**：若某法有自性我 → 其存在不依赖因缘（自性=不待他）。但该法是缘起法。自性（不待他）与缘起（待他）是互排相违。归谬：对方承许"有自性我"与其承许"诸法缘起"自相矛盾。

### 不立自宗

以上均为归谬——只从对方前提导出矛盾，不另立正相命题。中观师不建立"无我"作为独立实体。结论仅止于**无遮遮止**：对方所执的"自性我"在逻辑上不成立。

### 二谛与断灭边界

- **胜义谛**：一切法无自性我，以正理抉择不觅丝毫自性可得
- **世俗谛**：假名"我"在缘起层面可安立、有作用、有因果
- **断灭边界**：中观只破自性有，不破世俗缘起安立。把"无我"理解为一切法完全不存在、因果不存在——这是断灭，**不成立**。空性 = 无自性 ≠ 无显现。正因为自性空，缘起的因果、修行、解脱才能成立。

## 三、因明校验 / 因三相

```
论式：⟨五蕴（有法）⟩，应是⟨无自性我（所立法）⟩，以⟨缘起故（因）⟩。
```

| 三相 | 判定 | 依据 |
|------|------|------|
| **遍是宗法性** | ✅成立 | 五蕴有为，依因缘生灭，是缘起法 |
| **同品定有性** | ✅成立 | 存在同品（瓶）既无自性我、又是缘起法 |
| **异品遍无性** | ✅成立 | 异品（有自性我者）中绝无可能为缘起法——自性与缘起互排相违 |

因的类型：**自性因**（svabhāva-hetu）——缘起与无自性之间是同体相属关系，"缘起"的自性定义中已包含"无自性"。

## 四、摄类学 / 我所

### "我"与"我所"的总别关系

- **总与别**："我"执（总法）→ 执五蕴中有"自性我"；"我所"执（局部别法）→ 执某法属于"我"
- **周遍检查**：凡"我所"必依"我"，但依"我"之法不周遍为"我"；总灭则别随灭（我不成立→我所自然不成立）

### 无常→苦→无我的四句周遍

- **后遍**：无常 ⊆ 苦 ⊆ 非我 → 凡无常者必非我
- **违遍**：是我者必非苦、必是常 → 若"我"存在则必是常法
- **结论**：五蕴中无任何常法 → 五蕴中无"我"

### 总别混淆：日常应用

```
常见错误：一次批评 → "我没有价值"
摄类学拆解：批评=局部别法，人格价值=整体总法
不周遍：局部别法有问题，整体总法不因此被否定
```

## 五、观禅 / 触 → 作意 → 受 → 想 → 思

### 五遍行链路中"我"的构造

```
触（根境识和合）→ 作意（注意力定向）→ 受（领纳苦乐舍）
→ 想（取相归类：★"我"首次被构造——将五蕴现象组装成"有人在否定我"）
→ 思（意志发动：基于颠倒想造业）
```

**认知质量判定**：把五蕴和合的过程执为有"受伤害的我"——此为**颠倒知**，可降级为**犹豫识**并以**比量**校验。

### 观禅三智

| 智 | 观察内容 | 对治 |
|----|---------|------|
| **名色分别** | 名法（认知事件）≠ 色法（物质变化），无一法是"我" | 破粗分我执 |
| **缘摄受** | 因果链自运作，"动念是因，动作为果，不见有人我作" | 破作者我 |
| **三相印证** | 每环节审察无常→苦→无我，"能让委屈按意愿持续吗？→做不到" | 破主宰我 |

### 对治心所

念、慧、无瞋、行舍——以**念**觉察想心所构造"我"的刹那，以**慧**审察其颠倒性，以**无瞋**不被苦受驱动，以**行舍**安住于不执取。

## 六、边界：以上分析不等于修证

1. 本分析基于文本逻辑与概念工具的结构化推演，**非现量亲证**"无我"
2. 应成论式严格限定于归谬他宗，结论只破自性有，不立任何"无我"作为独立实体
3. 因三相校验证明推理有效，但有效推理≠已证得无我——从比量到现量需观禅直接体验
4. 观禅映射仅为方法论框架，**非心理治疗**；实修需**善知识指导**，不能替代专业心理支持或医疗处置
