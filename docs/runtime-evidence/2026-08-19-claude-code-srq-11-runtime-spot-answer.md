**结论：不成立。**"能盛水者"不能单独作为"瓶"的合格性相——它过宽，逆遍不成立，只能算"瓶"的一个共相/泛相，不是完整定义。

## 一、性相成立的标准

摄类学中，一个词要成为某所表的**合格性相**，须满足三项，其核心是**双向周遍（八门周遍）**：

1. **与所表同体**——性相与所表是同一本质、体性一；
2. **顺遍（凡是性相皆是所表）**——凡"能盛水者"皆是瓶；
3. **逆遍（凡是所表皆是性相）**——凡瓶皆是"能盛水者"。

第 2、3 条任一条不成立，该定义即不能成立。

## 二、逐项检验

- **逆遍（凡是瓶，皆是能盛水者）：** 基本成立。瓶以盛水为用，合格瓶必有能盛水之功用。
- **顺遍（凡是能盛水者，皆是瓶）：** **不成立。**

反例俯拾皆是：盆、碗、桶、杯、海、湖、河、地坑、手掬——**皆能盛水，却都不是瓶**。能盛水是"瓶"与无数器皿、乃至自然洼地共有的宽泛属性，不能把瓶从"非瓶的能盛水者"中区分出来。

## 三、为何错：周遍被反例击穿

设"能盛水者"为因、"瓶"为所立法：

- 有法：盆（或碗、湖、地坑）
- 是能盛水者，**成立**；
- 是瓶，**不成立**。

故"凡能盛水者皆是瓶"不周遍 → 定义过宽 → 性相不成立。

## 四、补足后的合格性相

标准定义需在"能盛水"之上补足瓶的**差别相**，经典表述为：

> **"大腹缩足能盛水者"**（鼓腹、缩足、能盛水，三要素缺一不可）。

其中"大腹、缩足"正是用来**排除**盆（宽口、无缩足颈）、碗（无大腹缩足之形）、桶（无缩足）、湖（非有相器物）等"能盛水而非瓶"的反例——补上差别相后，双向周遍才同时成立。
