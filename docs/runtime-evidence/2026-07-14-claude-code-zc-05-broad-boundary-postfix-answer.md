## 三、摄类学概念分析

### 3.1 "诸法"与"我"的总别关系

```
诸法（总）
├── 常法（别）
└── 无常法（别）
    ├── 色法
    ├── 心法
    └── 不相应行法
        └── 五蕴（局部别法集合）
```

- 若"我"是**整体总法** → 需周遍全部别法，但"我"不周遍于任何一蕴 → **总别混淆**
- 若"我"是某一**局部别法** → 将局部别法误认为整体总法 → **不周遍**且**不成立**
- "常一自在"的性相在五蕴中完全不可得

### 3.2 一与异的三层判别

- **自相异**：五蕴刹那生灭 vs "常"——与"常"的自性相违
- **返体异**：五蕴返体为"无常·有为法" vs "我"被执为"常法"
- **总聚异**：离五蕴外，无"我"的独立聚合体可得

三层皆异 → 五蕴中无自性我（摄类学词汇槽：**总与别**、**局部别法**、**整体总法**、**总别混淆**、**不周遍**、**不成立** 全部保留）。

## 四、应成论式构建与因三相验证

### 论式一：阿含33/34经直接应成式

若色是我 → 应能自主控制（自在）。实际不可控 → 与"我"的性相矛盾 → 色非我。

### 论式二：缘起归谬式（衔接中观）

- **对方承许**：法有自性我（自性有、常一自在）
- **归谬**：若法有自性有，则法不应依赖因缘（自性=独立自存）。但诸法确实是缘起法。**矛盾**：有自性者不依赖因缘，缘起者依赖因缘。
- **结论**：故"自性我"在缘起法上**不成立**。

### 因三相验证

- **第一相（遍是宗法性）**：五蕴是缘起法 ✓（杂阿含11经证据）
- **第二相（同品定有性）**：无自性我事物中，存在缘起法（瓶、柱、心法等）✓
- **第三相（异品遍无性）**：有自性我者中，完全不存在缘起法——"依赖因缘"与"不依赖因缘"是互排相违 ✓

**因三相完全满足。因是正因（自性因）。**

> 中观词汇槽全部保留：**对方承许**、**自性有**、**归谬**、**缘起**、**矛盾**、**不立自宗**。
